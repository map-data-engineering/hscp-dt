# HealthScope data releases

Data files for the HealthScope Mobile app (Tanzania health facilities and services).
Each release is published by `bundle-builder/publish_github.ps1`; please don't edit or
delete releases by hand. The app reads the manifest of the release marked "Latest".

Facility data: HealthScope ETL (Malaria Atlas Project). Map data © OpenStreetMap
contributors (ODbL), processed by Protomaps.
